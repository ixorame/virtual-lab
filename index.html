Virtual Lab

Theory

Ohm’s Law states that the current flowing through a conductor is directly proportional to the voltage across it, provided temperature remains constant.

V = I × R

Procedure

  1. Set the resistance value.
  2. Vary the voltage using the slider.
  3. Note the current value.
  4. Add readings to the table.
  5. Plot the V–I graph.

Controls
